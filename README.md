# Driver Drowsiness Detection using Deep Learning

## Project Overview

This project detects driver drowsiness using deep learning and image classification.

The system classifies the driver's condition into four categories:

- Closed
- Open
- No Yawn
- Yawn

Two deep learning models are used in this project:

- Custom CNN
- MobileNetV2

## Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Pillow
- Streamlit

## Models

### Custom CNN
The Custom CNN model is saved as:

`custom_cnn_model.keras`

### MobileNetV2
The MobileNetV2 model is saved as:

`mobilenetv2_model.keras`
